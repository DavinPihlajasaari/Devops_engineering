[Attendance Checker]

An attendance checker for educators and bosses the world over.

Features

  • Feature 1: Checks attendance based on barcode on the back of student cards.
  • Feature 2: saves each classes attendance separately.
  • Coming Soon: Better UI.

Tech Stack

Component Tool Version
Frontend GTK 3.24.51
Backend C C23
Datastorage CSV
Styling GTK 3.24.51

Installation

To get the app running locally, follow these steps:

  1. Clone the .exe file attendance_v0.9_boxed.exe
  2. Create folder
  3. place .exe file in folder
  4. Run the app

Usage

To help a manager or teacher keep attendance. Just use a barcode or other scanner that outputs a unique string and it will hash that as a ID for that persons card.
